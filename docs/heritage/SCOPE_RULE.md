# قاعدة نطاق الحصر (حكم المالك — 2026-11-21)

> **تُطبَّق على كل مصدر ومكتبة، مش بودليان بس.** أي حصاد جديد يتفلتر بالقاعدة دي.

## يُضاف (التراث المسيحي بكل لغاته)
- **قبطي** (بحيري/صعيدي/فيومي…)
- **عربي مسيحي** (قبطي-عربي، طقسي، كتاب مقدس، سير قديسين)
- **يوناني** (كتاب مقدس، آبائي، طقسي)
- **لاتيني** (آبائي، مسيحي)
- **سرياني · حبشي (جعز) · أرمني · جورجي**

## يُستبعَد
- **اليهودي:** عبري، جنيزة، يهودي-عربي (Judaeo-Arabic)، تلمود، توراة، تفاسير حاخامية.
- **الإسلامي:** قرآن، فقه، حديث، تصوف، أدب فارسي/تركي، مخطوطات إسلامية.
- **العلماني غير المسيحي.**

## ملاحظة تطبيقية
- "عربي" = **عربي مسيحي** في سياق التراث القبطي، مش أي عربي (الإسلامي مستبعَد).
- الوسوم في المكتبات ممكن تكون غلط (مثال: بودليان وسم كتب عربية إسلامية "Latin") — العبرة بالمحتوى الحقيقي مش الوسم.
- مصر مستثناة من المواقع (الحصر للتراث خارج مصر).
