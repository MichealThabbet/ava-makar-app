## الخلاصة والاقتراح
- **عندنا بالفعل:** الفاتيكان، BnF/Gallica، BL، بودليان، كامبريدج، تشستر بيتي، ديوك، برلين، ÖNB (جزئي)، مورجان، AUC، المتروبوليتان.
- **أهم جديد يستاهل ملاحقة:** Coptic OT (copt-ot) و PAThs (دول بيجمّعوا روابط المصوّر لكل مكتبة = اختصار كبير)، سيناء (EMEL/UCLA)، Beta masaheft (حبشي)، Matenadaran (أرمني)، منجانا، ميشيجان APIS، هايدلبرج.
- **مصر مستثناة** حسب تعليماتك (المتحف القبطي، نجع حمادي) — مذكورة للمرجع بس.
